# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-02-04

### Added
- Initial release
- Core property-based testing framework
- Generator system with composable generators
- Primitive generators (integer, float, boolean, string, etc.)
- Collection generators (array, object, tuple, record, set, map)
- Command-based (model-based) stateful testing
- React integration with ReactSystem
- Vitest integration with propTest and commandTest
- Complete TypeScript support
- Example tests demonstrating basic and command-based testing
